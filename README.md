# snoote.github.io — сайт разработчика

Статический сайт на GitHub Pages (репозиторий должен называться ровно `snoote.github.io`,
тогда он открывается по адресу https://snoote.github.io/).

- `index.html` — страница разработчика. Её адрес указывается в App Store Connect как Marketing URL,
  и на странице приложения он показывается как «Developer Website».
- `pixelhoops/privacy.html` — политика конфиденциальности Pixel Hoops:
  https://snoote.github.io/pixelhoops/privacy.html (её же указать в AdMob и App Store Connect).
- `app-ads.txt` — подтверждение для AdMob, должен лежать в корне сайта:
  https://snoote.github.io/app-ads.txt
